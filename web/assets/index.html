系统概况

端口占用

系统服务默认隐藏。「停止 / 强杀 / 重启」都要求携带进程创建时间，PID 被复用时会拒绝操作。

启动程序

「禁用 / 启用」通过 launchctl 立即生效：正在运行的进程不会停，但登录后不再启动，这个标记重启后依然有效。删除 LaunchAgent 则是真正移除它（移入废纸篓，可恢复）。

已安装的应用

卸载列表

点上面应用行的「卸载」把应用加进这个列表，确认无误后一次性「移到废纸篓」。删除一律进废纸篓，可随时恢复。高风险项（特权辅助工具、Group Container、系统级后台服务）默认不勾选。

可清理项

扫描需要遍历缓存目录并统计实际占用（按 APFS 已分配空间计算，不含克隆），首次可能需要几秒。删除一律移入废纸篓，可随时恢复。

环境变量

环境变量是怎么回事？看这里

macOS 上的环境变量其实有三层，mymac 只能改其中两层。 所以「保存后立刻生效」这句话，有前提条件。

能改 第 ① 层 · Shell

管什么：之后新开的终端。

怎么做的：mymac 把变量写进 ~/.config/mymac/env.sh， 再在 ~/.zshenv 里加一段标记块去引用它：

# >>> mymac env >>>
[ -f "$HOME/.config/mymac/env.sh" ] && . "$HOME/.config/mymac/env.sh"
# <<< mymac env <<<

用 .zshenv 而不是 .zshrc：zsh 启动时 .zshenv 最先读， 所以非交互 shell、脚本、IDE 内置终端都能读到。

⚠️ 已经打开的终端不会变。 在那个终端里执行 source ~/.config/mymac/env.sh 即可。

能改 第 ② 层 · launchd

管什么：之后新启动的图形界面程序—— 从 Dock 启动的 Xcode、IDEA、VS Code、微信等。终端程序不算， 它们走第 ① 层。

怎么做的：launchctl setenv KEY VALUE。 写完之后 mymac 会用 launchctl getenv 读回来核对， 对不上会如实告诉你，而不是假装成功。

⚠️ 已经在运行的程序不会变，只能重启它。 表格里会标出「N 个应用需重启」。

⚠️ 重启电脑后这层会丢失（launchd 的变量不持久）。 所以有「登录代理」：它在每次登录时把变量重新写一遍。

改不了 第 ③ 层 · 已运行的进程

已经在跑的进程，它的启动环境在进程创建时就固定了， 外部改不了。这是操作系统的限制，不是 mymac 的 bug。

唯一的办法是让程序自己重读（source）或者把它重启。

只读 下面四个标签页是什么
mymac 管理你在这里增删改的变量，改完立刻按上面两层生效。
launchd 环境当前 launchd 里实际有的变量（只读）。别人（比如别的工具）设的也在里面。
Shell 配置你的 .zshenv、.zprofile、.zshrc 里写的 export（只读）。mymac 不改这些文件，只加自己那一段标记块。
当前进程mymac 自己启动时拿到的环境（只读），用来对照参考。

如果同一个变量在多处出现，「冲突」标记会告诉你谁会覆盖谁。

其它按钮
PATH 编辑器只加片段，不整体覆盖。写成 export PATH='片段':"$PATH" 这种动态形式，你以后再改 PATH 也不会被写死。
登录代理登录时把变量重新写进 launchd，解决「重启后丢失」。
备份每次改 .zshenv 前自动备份，可一键恢复。
导入 / 导出JSON 或 .env 格式；导入前会先显示差异让你确认。
